# Journey-To-Defeat-K.Man-OLD-ROBLOX-VERSION-

Hello! About a year ago I was trying to recreate the engine and make a joke fan game from one of the games from the MOTHER® or EARTHBOUND™ franchise. After a long time I decided to hop on another game engine and left this game behind.

[Find open-sourced experience at the bottom]

What this game currently has:

* Transitions to combat scene.
* Scrolling health bars.
* Menu Icon selection.
* Working "Bash" Mechanic.
* Working "Goods" Mechanic.
* Working Oscillating backgrounds.
* Working "pixel-perfect" view port.
* Custom text font that's compatible with the pixel-perfect view port.

What's unfinished or broken within this game.

* Unfinished "Bash" VFX.
* Temporary PSI VFX was rushed.
* Enemies have infinite health (temporary, was going to fix that earlier).
* Party Members can't die (temporary, was going to fix that earlier).
* There's no existing way of winning or leaving the battle.
* The "Run" function doesn't work.
* The "Defend" function doesn't work.
* Keyboard button X doesn't work.
* Some audio isn't present (non-existent).
* ONLY PC SUPPORT.

Declarations:

* Some assets (mainly sprite sheets) are righted to Shigesato Itoi, Nintendo, EARTHBOUND™, and the MOTHER® franchise.
* This experience will not profit in any way and is not intended to violate the rights of the copyright owner.
* This experience is an unfinished MOTHER® fan game project.
* This experience is open-sourced and will not be worked on anymore.

HOW TO INTERACT
* Use the arrow keys (←↓↑→) to select.
* Press Z to interact.
* Press X to cancel. (won't do anything)

So, here's what the game has in store. Feel free to give some feedback as well!
